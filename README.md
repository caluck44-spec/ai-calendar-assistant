# AI 日历助手网页版

这是 AI 日历助手的 GitHub Pages 静态网页版本。

## 使用方式

1. 在「设置」中填入自己的 DeepSeek API Key。
2. 粘贴聊天记录、通知或其他文字并分析。
3. 勾选需要的事件，点击「一键导出日历文件」。
4. 在 iPhone 上用 Safari 打开网页，选择「分享」→「添加到主屏幕」→「作为 Web App 打开」。

## 重要说明

- 本版本不包含任何 API Key、密码或账号信息。
- API Key 只保存在当前设备的浏览器本地数据中，不会自动同步到电脑。
- GitHub Pages 只负责托管网页；它不提供历史记录云同步，也不能直接读写 iPhone 的系统日历。
- 手机端通过 `.ics` 文件导入日历，提醒事项可以在 iPhone 上继续手动确认。
